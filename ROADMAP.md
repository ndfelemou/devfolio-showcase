# 🚀 Roadmap du Portfolio Devfolio-Showcase

Ce document liste les fonctionnalités prévues pour améliorer le portfolio.

## 🎨 1. Amélioration Visuelle & UX (Frontend) - [EN COURS]
- [ ] **Filtrage Dynamique des Projets** : Pouvoir filtrer par catégories et technologies.
- [ ] **Skeleton Loading** : Améliorer la perception de vitesse avec des placeholders animés.
- [ ] **Progress Bar de Lecture** : Pour les articles de blog.
- [ ] **Section Témoignages** : Affichage des recommandations professionnelles.

## 📊 2. Analytique & Stats (Dashboard Admin) - [EN COURS]
- [ ] **Graphiques de Compétences** : Visualisation de la répartition technique (Recharts).
- [ ] **Cartes de Statistiques** : Vue d'ensemble rapide (nb projets, messages, etc.).

## 🛠️ 3. Fonctionnalités "Pro"
- [ ] **Multi-langue (I18n)** : Support Français / Anglais.
- [ ] **Visionneuse CV PDF** : Prévisualisation directe sans téléchargement obligatoire.
- [ ] **Export de Données** : Export des messages au format CSV/Excel.

## ⚙️ 4. Préparation Backend (NestJS)
- [ ] **Intercepteurs d'erreurs globaux** : Gestion centralisée des retours API.
- [ ] **Optimisation de la gestion des images** : Prévisualisation avant upload.
